# Bravix Next Starter

Production-ready Next.js starter by **Bravix Creative**.

Built for modern, multilingual and scalable web projects.

## Features

- Next.js App Router
- TypeScript
- Tailwind CSS
- next-intl
- Multilingual routing
- SEO metadata foundation
- Sitemap
- Robots configuration
- Open Graph
- Twitter metadata
- Scalable project architecture

## Locales

- English
- Turkish
- Russian

## Getting Started

```bash
npm install
npm run dev
